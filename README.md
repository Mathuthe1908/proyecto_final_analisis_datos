# 📊 Análisis de Datos de E-Commerce y Ventas Globales

Proyecto final desarrollado para el curso de Análisis de Datos — Universidad Tecnológica Nacional (UTN). 

El objetivo de este trabajo es explorar, limpiar y visualizar datos comerciales de E-Commerce para responder preguntas clave del negocio vinculadas al impacto de los descuentos, los costos de envío, la satisfacción del cliente y la distribución de ingresos por categoría y país.
